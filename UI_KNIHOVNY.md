# UI knihovny (layouty, animace, komponenty)

Nainstalované verze jsou připnuté přesně (`--save-exact`) a jsou starší než dva týdny od vydání.
Pro další práci na layoutech používej tyto knihovny místo vlastního kódu, pokud dávají smysl.

| Knihovna | Verze | Účel |
|---|---|---|
| `lucide-react` | 1.61.0 | Konzistentní SVG ikony místo emoji |
| `motion` | 14.6.0 | Animace a přechody (vstupy, gesta, layout animace) |
| `@formkit/auto-animate` | 0.10.0 | Zero-config animace seznamů a přeskládání (karty, filtry) |
| `@radix-ui/react-tabs` | 1.2.1 | Přístupné záložky |
| `@radix-ui/react-progress` | 1.2.1 | Přístupný progress bar |
| `@radix-ui/react-tooltip` | 1.4.1 | Přístupné tooltipy |
| `sonner` | 2.0.8 | Toast notifikace |
| `canvas-confetti` | 1.9.4 | Oslavný efekt (např. vyzvednutí odměny) |
| `clsx` | 2.1.1 | Skládání podmíněných tříd |
| `tailwind-merge` | 3.7.0 | Slučování konfliktních Tailwind tříd |

Pravidlo pro aktualizace: nová verze se přidá jen tehdy, je-li starší než dva týdny od vydání.
