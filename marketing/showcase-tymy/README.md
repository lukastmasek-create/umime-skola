# ucimesehrou.org/tymy showcase (3 parts, 1920x1080, 30 fps)
Sources for the landscape showcase videos. They build on the engine in `lukastmasek-create/shorts` (branch `claude/eloquent-mendel-zow67i`): copy these files into that checkout at the same paths, apply `Root.tsx.patch`, then `node 2d/tymy_build.mjs` (lint + scenes.json), `python3 audio/tymy_sfx.py 2d/tymy-01/scenes.json public/tymy-01/sfx.wav`, `scripts/render_all.sh`.
MP4 files are not committed.
